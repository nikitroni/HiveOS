# HiveOS — Скриншоты

Этот файл временный: он нужен, пока в документации стоят заглушки с [placehold.co](https://placehold.co). После того как ты добавишь реальные скриншоты и заменишь URL, его можно удалить.

## Какие скриншоты нужны

Сохрани каждый файл в **`docs/screenshots/`** с точным именем из таблицы.

| Файл | Что должно быть на скриншоте |
|---|---|
| `heartos_main.png` | Главное меню HeartOS: заголовок `=== HeartOS Control Center ===` и кнопки **Configure BeeOS**, **Configure LabOS**, **Configure Hive**, **LIBRARY**. |
| `beeos_hive_map.png` | Технический монитор BeeOS со списком / детальным экраном ульев и живыми цветами статуса: зелёный = улей есть, светло-серый = пусто, жёлтый = выбран. |
| `labos_breeding.png` | Главный монитор LabOS во время цикла разведения: прогресс цикла и лог улучшений. |
| `breeding_setup.png` | Физическая связка разведения в мире: камера разведения, инкубатор, реле, кликер Just Dire Things и подключённые сундуки. |
| `hive_setup.png` | Физическая связка одного улья: блок улья, его Block Reader и редстоун-реле. |

## Формат и путь

- **Путь:** `docs/screenshots/<имя>.png` (например, `docs/screenshots/heartos_main.png`).
- **Формат:** PNG.
- **Разрешение:** рекомендуется 1920×1080; подойдёт любой размер 16:9 или пропорции монитора в игре.
- **Кадр:** монитор (или блоки в мире) занимает большую часть кадра, чат и HUD не перекрывают важное.

## Как заменить заглушку

1. Сделай скриншот в игре.
2. Сохрани его в `docs/screenshots/` с точным именем из таблицы.
3. Замени соответствующий URL `https://placehold.co/...` в документации на путь к файлу.

Было:

```markdown
![Главное меню HeartOS](https://placehold.co/800x450/1e1e1e/ffffff?text=HeartOS+Main+Menu)
```

Стало:

```markdown
![Главное меню HeartOS](docs/screenshots/heartos_main.png)
```

Префикс пути зависит от файла:

- В `README.md` и `README.ru.md` (корень репозитория) — `docs/screenshots/<имя>.png`.
- В файлах внутри `docs/` (например, `docs/setup.ru.md`, `docs/systems.ru.md`) — `screenshots/<имя>.png`.

## Если нужно несколько скринов для одной системы

Если одной картинки мало (например, хочется показать экран и связку блоков), выстрой их рядом таблицей без границ — так GitHub отрисует их в ряд:

| Шаг 1 | Шаг 2 |
|-------|-------|
| ![step1](docs/screenshots/step1.png) | ![step2](docs/screenshots/step2.png) |

Внутри `docs/` не забудь про префикс `screenshots/...` вместо `docs/screenshots/...`.

## Про 3D-виды

Веб-просмотрщики схем вроде **Shulkr** и **MineSchematic** не знают модовые блоки (Productive Bees, Just Dire Things и т. п.), поэтому корректный 3D-рендер связки через них не получится. Варианты для документации:

- **GIF-анимации** — короткая запись, как работает связка (лучше всего передаёт динамику).
- **Несколько скриншотов с разных сторон** — статично, но надёжно и без внешних сервисов.
- **Ссылка на внешний просмотрщик** — только если он действительно поддерживает нужные блоки.

Для v1.0 достаточно **GIF + скриншотов с разных сторон**.
